## Assets in this folder

- `logo.svg` — 800×800 mark for the **profile picture** (renders cleanly inside
  YouTube's circular crop).
- `banner.svg` — 2560×1440 **channel banner**; all text sits inside the 1546×423
  centered safe area so nothing is cut on phone/TV/desktop.

## How to use

YouTube needs raster images, so export the SVGs to PNG/JPG:

```powershell
# If you have Inkscape:
inkscape assets/branding/moneywise/logo.svg   --export-type=png -w 800  -h 800  -o moneywise_logo.png
inkscape assets/branding/moneywise/banner.svg --export-type=png -w 2560 -h 1440 -o moneywise_banner.png
```

Or open the .svg in any browser and screenshot, or drop it into Figma/Canva to
export. Then: YouTube Studio → Customization → Branding (picture) and Banner.

Specs: profile picture 800×800 (98 KB+ ok, ≤4 MB); banner 2560×1440, keep the
"safe area" 1546×423 centered (already respected in banner.svg); ≤6 MB.
