> **Class:** snapshot · **Status:** frozen · **Reviewed:** 2026-10-28

Every idea of [bridge_plan.md](bridge_plan.md) (#1597-#1896) scored on one rule, so the waves pull
the biggest levers first. These are judgments, written down so they can be argued with: the
scores are data in the script that made this page, and a wrong one is corrected there and the
page re-made - not edited by hand.

**Score = Effect x Confidence x Urgency / Effort.**

| term | values | meaning |
|---|---|---|
| Effect | 1-5 | how far the lane's number can move if the idea works |
| Confidence | 3 / 2 / 1 | measured on this channel / known platform behaviour / a guess |
| Urgency | 2 / 1.5 / 1 | the GTA 6 window before 11-19 / a dated event before 2027-02-01 / any time |
| Effort | 1 / 2 / 4 | the backlog size S / M / L |

A measurement idea scores low on its own (Effect 1) even when later ideas need it; the waves
in [bridge_plan.md](bridge_plan.md) put the few that unblock others (the scoreboard) early anyway.
